# macOS project compatibility

Linux projects preserved their document data and cached pixels in 15 round trips through the upstream Swift reader/writer on a Mac. Full macOS application testing remains unverified.

**Keep the original Linux project when sharing RAW work.** The Mac writer preserves the developed pixels but discards the embedded RAW source and development settings, preventing further RAW development in the returned file.

## Tested coverage

Tests ran September 26, 2026 using the [upstream reader/writer at `2309a85`](https://github.com/robbietilton/Compositor/tree/2309a85601824465aac5ebc1f45c4b8b9f78a5c1) on macOS 15.8.

| Direction | Cases | Coverage | Result |
| --- | ---: | --- | --- |
| Linux → Mac reader/writer → Linux | 4 | All 12 adjustments and 24 blend modes, groups, masks, clipping, transforms, guides, shapes, six effects and Unicode text colors | Document data and decoded pixels preserved |
| Mac reader/writer → Linux → Mac reader/writer → Linux | 11 | Basic v1–10 projects and a v10 project with Unicode color ranges, paragraph bounds, effects and transforms | Document data and decoded pixels preserved |
| Linux RAW extension → Mac reader/writer → Linux | 1 | Cached pixels, embedded source and development settings | Pixels preserved; RAW source and settings discarded |

The older-version fixtures were generated by the current Swift writer with manifest versions 1–10 and basic fields. They are not historical files from each released app. Linux resaves them as v10. The RAW case tested package persistence with synthetic source bytes, not camera decoding.

## What these tests do not establish

These tests used the upstream project reader/writer in a command-line harness. The released Compositor 1.3.3 app requires macOS 26.5 and could not run on the macOS 15.8 test system. GUI workflows, text/font rendering and effects/compositing fidelity remain unverified. Preserving cached pixels does not establish identical rendering on both platforms.

See the [fixture provenance](../tests/fixtures/macos/README.md) and [regression test](../tests/macos_project.rs) for technical details.
