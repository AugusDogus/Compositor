# macOS project compatibility

Tested September 26, 2026 using a physical Intel Mac running macOS 15.8 and Swift 6.1.2 (Xcode 16.4). All 15 positive project round trips preserved the Linux document model exactly, including decoded raster and mask pixels.

| Direction | Cases | Coverage | Result |
| --- | ---: | --- | --- |
| Linux → upstream Swift on Mac → Linux | 4 | All 12 adjustments, all 24 blend modes, groups, opacity, masks and unlinked placement, clipping, transforms, guides, three shapes, six effects, Unicode text colors and an empty raster layer | Exact document equality |
| Upstream Swift on Mac → Linux → upstream Swift on Mac → Linux | 11 | Simple fixtures for schema versions 1–10, plus a v10 fixture with Unicode color ranges, paragraph bounds, six effects, transform, guide and resolution | Exact document equality |
| Linux RAW extension → upstream Swift on Mac → Linux | 1 | Cached pixels plus embedded source bytes and development settings | Pixels and standard document data preserved; Linux RAW source/settings dropped |

The older-version fixtures were generated by the current Swift writer with manifest versions 1–10 and basic fields. They are not historical files from each released app. Linux resaves them as v10.

## Method and regression coverage

The Mac ran the upstream reader/writer from [commit `2309a85`](https://github.com/robbietilton/Compositor/tree/2309a85601824465aac5ebc1f45c4b8b9f78a5c1), using Foundation and AppKit for native file and PNG handling. A command-line harness extracted schema definitions and validators, removed type-level `nonisolated` syntax unsupported by Swift 6.1, and omitted UI/render-only members, filter dispatch and an unused raster cache. ProjectStore read/write and validation logic remained unchanged.

A [Mac-generated fixture](../tests/fixtures/macos/README.md) is committed with a [Linux regression test](../tests/macos_project.rs):

```sh
cargo test --locked --test macos_project
```

The additional RAW check used opaque synthetic source bytes to test package persistence, not camera decoding. The Mac writer reconstructs packages using the upstream manifest and PNG assets, omitting `linux-raw.json` and `raw/`. Keep the original Linux package to preserve RAW redevelopment. The original test package remained unchanged.

## Not verified

The official Compositor 1.3.3 app declares a minimum macOS version of 26.5, so it could not run on this laptop. These are source-level file-format tests, not full-app tests. GUI workflows, text/font rendering, effects/compositing fidelity, and Photoshop application round trips remain unverified. Cached pixel equality does not establish identical rendering on both platforms.
