# Linux screenshots

The workspace screenshot is a real capture of the 0.1.0 AppImage at Linux commit `0517e1b`, taken on September 20, 2026 under nested Wayland. It is cropped to the application's 1280 × 800 content, removing the test desktop and its outer window decoration. No application controls or image results were altered.

- [Workspace](workspace.png): background removal applied as an editable layer mask, with transform controls visible.

The photograph is the public-domain NASA portrait of astronaut Eileen Collins, distributed as [`skimage.data.astronaut`](https://scikit-image.org/docs/0.25.x/api/skimage.data.html#skimage.data.astronaut). It was used as the image fixture for the native Vulkan inference checks.
