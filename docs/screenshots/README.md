# Linux screenshots

The workspace screenshot is a native X11 capture of the current Linux source with the macOS 1.2.0 additions, Sampling toolbar fix, and corrected effects button styling, taken on September 21, 2026. It shows the Ubuntu 24.04 release build after v0.3.0, not the published v0.3.0 AppImage. The capture is the application's complete 1280 × 800 window, with no controls or image results altered.

- [Workspace](workspace.png): background removal applied as an editable layer mask, with transform controls visible.

The photograph is the public-domain NASA portrait of astronaut Eileen Collins, distributed as [`skimage.data.astronaut`](https://scikit-image.org/docs/0.25.x/api/skimage.data.html#skimage.data.astronaut). It was used as the image fixture for the native Vulkan inference checks.

The portrait retains its original pixels and a previously generated native BiRefNet mask as an editable layer mask. The project was saved as format v8 and reopened before capture.
