## New in v0.4.0

- Outer Glow with editable color, size, opacity and visibility, rendered on GPU and CPU. Supports undo, copying between layers and project saving.
- Brush and eraser stroke smoothing, including layer masks, with a 0–100 screen-space control and consistent behavior across zoom levels.
- All projects now save as `.comp` v8, preserving folder opacity for current macOS readers. Older v1–v7 projects remain readable and upgrade when saved.
- Sampling stays visible beside Cancel and Apply on narrow windows. Corrected the layer-effects button styling and refreshed the workspace screenshot.

The feature target is Compositor for macOS 1.2.0. Existing PSD conversion limits and unverified real macOS project round trips remain documented in the [feature comparison](https://github.com/AugusDogus/Compositor/blob/v0.4.0/docs/linux-features.md).
