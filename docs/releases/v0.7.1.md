## Fixed in v0.7.1

- Fixed the multi-second freeze when dragging gradients across large images. Previews run in the background, use Vulkan where supported, and discard superseded requests. Cancel and undo restore the original image.
- Magic Wand selection and the final healing calculation now run outside the UI thread.
- Blur brushes reuse overlapping work and use Vulkan for Gaussian filtering.
- Smudge and Liquify update the painted region instead of scanning the entire layer on every move.

Large brushes can still lag, particularly Smudge and Liquify. CPU-only Blur remains slower. This release improves responsiveness without changing the project format or editing feature set.
