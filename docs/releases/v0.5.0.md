## New in v0.5.0

Targets the editing feature set of Compositor for macOS 1.2.9.

- Camera Raw Filter with live previews, interactive curves, color grading wheels, sampling tools, scopes, guided geometry and GPU processing.
- 24 blend modes, Inner Glow, Black & White, Color Balance and Invert adjustments, plus editable Gaussian Blur, Motion Blur and Add Noise layers.
- Vignette, Bloom and Tonal Contrast filters, and Image Trim by transparency or corner color.
- Broader camera RAW support through bundled LibRaw, including Fujifilm X-Trans. Editable development and direct 16-bit TIFF export remain available.
- PSD/PSB import with supported editable text and additional color adjustments.
- Editable layer copying across projects, improved multi-layer duplication and clipping preservation, crop presets, text interaction and persistent tool preferences.
- Projects now save as `.comp` v9. Versions 1–9 remain readable; older applications may not open newly saved projects.
- Faster eyedropper sampling with blur layers, cached Camera Raw GPU pipelines and scopes, bounded GPU readback, and allocation checks for large sparse canvases.
- Automatic update checks now include AppImages. Installing an update still means downloading and replacing the AppImage after closing the editor.

Validation: 825 ordinary tests passed, plus explicit NVIDIA GPU checks and Photoshop/RAW fixture tests. Formatting, Clippy and the optimized build passed. Physical AMD hardware and reopening exports in the macOS or Photoshop applications remain unverified. See the [feature comparison](https://github.com/AugusDogus/Compositor/blob/v0.5.0/docs/linux-features.md) for compatibility limits.
