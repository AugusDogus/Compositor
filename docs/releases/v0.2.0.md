## Changes in 0.2.0

- Add editable text, GPU layer effects, line shapes, selection feathering, Soft Light, folder opacity and duplication, and a customizable keyboard-shortcuts editor.
- Add layered PSD import/export, including editable primitive shape imports and Levels, Curves and Hue/Saturation import/export.
- Add offline SAM 3.1 object selection by click or box.
- Add rulers, guides, grid, snapping and Open from Clipboard.
- Preserve the new editable features in native projects and fix concurrent Vulkan initialization in offscreen rendering.

Targets the macOS 1.1.6 feature inventory. PSD shape exports are rasterized; text and smart objects use cached pixels. Unsupported conversions are reported. Opening exported files in Photoshop or Linux-saved projects in the macOS application remains unverified. CPU and NVIDIA inference are tested; physical AMD hardware is unverified.
