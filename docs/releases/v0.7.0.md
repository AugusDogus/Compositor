## New in v0.7.0

Targets the editing feature set of Compositor for macOS 1.3.3.

- Editable perspective preserves original pixels, text, shapes and RAW sources. Reopen the transform to adjust corners without repeatedly resampling the image.
- Artboards, per-layer PNG export and export-size presets. Create editable size variants or export several sizes at once.
- Pen paths with editable Bézier anchors and handles, path selections, painting and shape layers.
- Photo Filter, Channel Mixer, Selective Color, Threshold, Posterize, Vibrance and Shadows/Highlights, available as pixel edits or editable adjustment layers.
- Pattern Overlay with Photoshop PAT import, Gradient Overlay, Bevel/Emboss and Gray Blend If split handles.
- Dodge, Burn and Sponge brushes; sampled ABR, GBR and GIH brush import; editable multi-stop gradients.
- Brightness/Contrast, radial blur, Unsharp Mask, High Pass and luminosity sharpening. Fade adjusts the last raster edit; History lets you return to retained undo states.
- Still GIF and AVIF export, compressed SVG import, canvas rotation and embedded PSD color-profile conversion. Supported Photoshop effects remain editable on export.
- Light, dark and live Omarchy themes, plus fixes for toolbar layout, large dialogs, no-op edits and RAW project validation.
- AppImage, DEB, RPM and Arch packages for x86_64 and ARM64, each bundling offline background-removal and object-selection models.

Save a Linux `.comp` project to retain Linux-only sources and settings. macOS and PSD receive rendered fallbacks for unsupported features; Photoshop export round trips and full macOS application compatibility remain unverified. ARM64 desktop use, physical AMD GPUs and tablets remain unverified. See [feature and format limits](https://github.com/AugusDogus/Compositor/blob/v0.7.0/docs/linux-features.md).
