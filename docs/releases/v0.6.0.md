## New in v0.6.0

Targets the editing feature set of Compositor for macOS 1.3.3.

- Per-character text colors and `.comp` v10 projects. Versions 1–10 remain readable; older applications may not open newly saved projects.
- Dither, halftone, Mac patterns and ASCII filters, plus SVG import with text and embedded images.
- Open Recent, external project reload and background saving. Continue editing while a save completes; competing saves preserve both versions.
- Autosave snapshots every 30 seconds and crash recovery. Undo history, unfinished dialog edits and changes after the last completed snapshot are not recovered.
- Native Wayland and X11 tablet pressure, tilt and eraser input. Physical tablet hardware remains unverified.
- Colored adjustment tracks, individual resets and draggable numeric labels.
- Safer large PSD/PSB imports, painting beyond mask bounds, clearer selection outlines and fixes for focus and unfinished edits when closing projects.

File-format round trips through the upstream Mac reader/writer preserve tested document data and pixels. Full macOS application and Photoshop export round trips remain unverified. Mac saves discard embedded Linux RAW sources and settings; keep the original Linux project for redevelopment. Physical AMD hardware remains unverified. See [compatibility details](https://github.com/AugusDogus/Compositor/blob/v0.6.0/docs/linux-features.md).
