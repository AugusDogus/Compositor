# Interface font

Inter Variable, version 4.001 (`git-9221beed3`), by Rasmus Andersson and the Inter Project Authors.

Source: https://github.com/rsms/inter. SHA-256: `4989b125924991b90d05b2d16e0e388c48f7d5bb8b30539bbf9c755278d0ccaf`.

Compositor embeds the upright variable font for consistent interface typography across Linux distributions. System fonts provide fallback glyphs.

The [SIL Open Font License](INTER-LICENSE.txt) is included in Linux packages.
