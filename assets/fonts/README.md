# Interface font

Inter Variable, version 4.001 (`git-9221beed3`), by Rasmus Andersson and the Inter Project Authors.

Source: https://github.com/rsms/inter. The unmodified font was copied from this environment's `inter-font` package. SHA-256: `4989b125924991b90d05b2d16e0e388c48f7d5bb8b30539bbf9c755278d0ccaf`.

The application embeds the upright variable font for consistent menu, field and panel typography across Linux distributions. It was selected by comparing actual Noto Sans and Inter captures with the upstream macOS references, at equal scale. Inter is an open font substitute for Apple's system typeface; it is not SF Pro. System fonts provide fallback glyphs.

The SIL Open Font License is preserved in `INTER-LICENSE.txt` and included in Linux packages.
