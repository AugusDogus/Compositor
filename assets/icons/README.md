# Interface icons

Lucide icons are pinned to commit `ba6751ac45d379f6359d75ef2228cff6ba96c122` of
[Lucide](https://github.com/lucide-icons/lucide), under the [ISC license](LICENSE).
`trash-2.svg` is the local name for upstream `trash.svg`.

The `compositor-*` glyphs are project assets inspired by the original Compositor
controls, distributed under the [project license](../../LICENSE). They are not
Apple SF Symbols. Curves, exposure, grain, hue, masks and layer controls follow
the original Swift interface. The gradient pattern comes from
`Compositor/UI/GradientControls.swift`; the clone stamp and polygonal lasso paths
come from `BrushControls.swift` and `LassoControls.swift`.
